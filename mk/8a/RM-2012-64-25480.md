# Закон за изменување на Законот за спортот

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Во Законот за изменување и дополнување на Законот за спортот („Службен весник на Република Македонија“ број 18/11), одредбата на членот 8 ќе почне да се применува од 1 јуни 2017 година.

##### Член 2

Овој закон влегува во сила осмиот ден од денот на објавувањето во „Службен весник на Република Македонија”.
