# Закон за дополнување на Законот за јавните патишта

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Во Законот за јавните патишта („Службен весник на Република Македонија" број 84/2008, 52/2009, 114/2009, 124/10, 23/11, 53/11, 44/12, 168/12, 163/13, 187/13, 39/14, 42/14, 166/14, 44/15, 116/15, 150/15, 31/16, 71/16 и 163/16 и „Службен весник на Република Северна Македонија“ број 174/21), во членот 65 по зборовите: „церебрална парализа,“ се додаваат зборовите: „хронично болни од најтежок облик на заболување од цистична фиброза“.

##### Член 2

Во член 66 во ставот (2) по зборовите: „церебрална парализа,“ се додаваат зборовите: „хронично болни од најтежок облик на заболување од цистична фиброза“.

##### Член 3

Овој закон влегува во сила со денот на објавувањето во „Службен весник на Република Северна Македонија“.
