# Закон за овластување на организација за изработка на пригодни ковани пари

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Се овластува АД СГОЛДМАКм Радовиш да изработи пригодни ковани пари во сребро и во злато по повод 2000 години од почетоците на христијанството.

##### Член 2

Овој закон влегува во сила осмиот ден од денот на објавувањето во „Службен весник на Република Македонија“.
