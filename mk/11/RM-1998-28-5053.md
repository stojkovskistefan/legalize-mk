# Закон за овластување на организација за изработка на пригодни ковани пари

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Со овластува АД СГОЛДМАК" Радовиш да изработи пригодни ковани пари од злато по повод 50 годишнината од егзодусот на Македонците од Егејскиот дел на Македонија.

##### Член 2

Овој закон влегува во сила осмиот ден од денот на објавувањето во „Службен весник на Република Македонија“.
