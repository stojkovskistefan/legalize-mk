# Закон за дополнување на Законот за стопанските комори

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Во Законот за стопанските комори („Службен весник на Република Македонија“ број 17/11), во членот 42 став (2) по зборот „економија“ се додаваат зборовите: „и труд“.

##### Член 2

Овој закон влегува во сила осмиот ден од денот на објавувањето во „Службен весник на Република Северна Македонија“.
