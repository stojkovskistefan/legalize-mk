# Закон за изменување и дополнување на Законот за трансформација на претпријатијата со општествен капитал

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Во Законот за трансформација на претпријатијата со општествен капитал („Службен весник на Република Македонија“ број 38/1993, 48/1993, 21/1998, 25/1999, 39/1999, 81/1999, 49/2000, 6/2002, 31/2003, 38/2004, 35/2006, 84/2007 и 123/12) во членот 50 по ставот 2 се додава нов став 3 кој гласи: „Постапката за избор на најповолна понуда ќе заврши со електронско јавно наддавање, преку електронски систем за јавно наддавање, согласно прописот од член 95 став 3 од овој закон.“ Ставот 3 станува став 4.

##### Член 2

Во членот 50 - б по зборовите: „доставувањето на понудите“ сврзникот „и“ се брише, а по зборовите: „содржината на понудите“ се додаваат зборовите: „и начинот на спроведување на електронското јавно наддавање за избор на најповолна понуда“.

##### Член 3

Се овластува Законодавно - правната комисија на Собранието на Република Македонија да утврди пречистен текст на Законот за трансформација на претпријатијата со општествен капитал.

##### Член 4

Овој закон влегува во сила осмиот ден од денот на објавувањето во „Службен весник на Република Македонија“.
