# Закон за изменување на Законот за придонеси од задолжително социјално осигурување

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Во Законот за изменување на Законот за придонеси од задолжително социјално осигурување ( “Службен весник на Република Македонија“ број 170/13), во членот 3 датата: “1 јуни 2014 година” се заменува со датата: “1 јануари 2015 година”.

##### Член 2

Овој закон влегува во сила со денот на објавувањето во „Службен весник на Република Македонија“.
