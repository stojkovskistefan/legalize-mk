# Закон за изменување на Законот за ветеринарно здравство

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

##### Член 1

Во Законот за ветеринарно здравство („Службен весник на Република Македонија“ број 113/2007, 67/10, 24/11, 136/11, 123/12, 154/15 и 53/16), членот 105-а се брише.

##### Член 2

Овој закон влегува во сила осмиот ден од денот на објавувањето во „Службен весник на Република Северна Македонија“.
